# 🌿 Zaytoon Garden Restaurant — Official Website

This is the premium, fully responsive website for **Zaytoon Garden Restaurant Multan**. Built with Next.js 15, Tailwind CSS 4, and Framer Motion for a luxury dining experience.

## 🚀 How to Run Locally

### 1. Enter the project folder
```bash
cd zaytoon-garden-web
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Setup Images
Run this script to copy the AI-generated food and ambiance images into the project:
```bash
node copy-images.js
```

### 4. Start the Server
```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the site.

---

## 🎨 Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS 4 (Beta)
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Fonts**: Playfair Display (Headings), Inter (Body)

## 📁 Project Structure
- `/src/components/sections`: All website sections (Hero, About, Menu, etc.)
- `/src/components/layout`: Global Navbar and Footer
- `/src/app/globals.css`: Design tokens and custom theme
- `/public/images`: All visual assets

## 🛠 Features
- ✅ Fully Responsive (Mobile, Tablet, Desktop)
- ✅ Floating WhatsApp Order Button
- ✅ Premium Reservation Form
- ✅ Category-based Menu Preview
- ✅ Masonry Image Gallery with Lightbox
- ✅ Interactive Location Map
